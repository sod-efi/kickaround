# Kickaround

Ask several AIs at once and get one verdict: the best move, why, and what's still open. [kickaround.app](https://kickaround.app)

## Install

**Claude Code**

```
/plugin marketplace add sod-efi/kickaround
/plugin install kickaround@kickaround
```

**Codex**

```
codex plugin marketplace add sod-efi/kickaround
codex plugin add kickaround@kickaround
```

Then sign in with Google when asked, and say "kickaround whether…" to use it.

**Claude, ChatGPT, Gemini or Cursor:** add `https://kickaround.app/mcp` as a custom connector in the app's settings.
